Projeto desenvolvido para a disciplina de Programação Orientada a Objetos (POO) da UFG.

O sistema tem como objetivo realizar o gerenciamento e a persistência de dados de filmes utilizando Python e arquivos CSV como DataSets. A aplicação foi desenvolvida utilizando conceitos de Programação Orientada a Objetos, como encapsulamento, modularização e separação de responsabilidades.

Funcionalidades atuais:
- Carregamento de filmes via CSV
- Listagem de filmes
- Busca por título
- Adição e remoção de filmes
- Filtragem por gênero
- Ordenação por nota
- Persistência de dados em CSV

Melhorias futuras:
- Integração com datasets do Kaggle
- Interface gráfica
- Recomendações de filmes
- Estatísticas e análises de dados
- Uso de pandas para manipulação avançada dos datasets
